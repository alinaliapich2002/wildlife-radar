# Живой радар

Открытая русскоязычная подборка практик маркетинга и коммерции океанариумов и зоопарков.

Статический сайт: index.html, style.css, app.js, data.json. Никаких ключей API или закрытых данных в репозитории нет.

Первоначальное содержимое — пилотная подборка, исторические материалы помечены.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
